# Notion LaTeX Auto Paste 0.6.14

This package adds rich clipboard support for images in ChatGPT responses. Use ChatGPT's answer-copy button, then paste into Notion: response text, copied images, and LaTeX formulas are carried together. Formula conversion remains handled by the Notion paste helper.

The ZIP contains `manifest.json`, `content.js`, `chatgpt-copy.js`, `INSTALL-WINDOWS.txt`, and `INSTALL-MACOS.txt`. Load the extracted folder through `chrome://extensions` with Developer mode enabled.
